# auto-beta: X·Xᵀ最大固有値によるβ自動決定

## 目的・前提・方針案

- **目的**: Tikhonov正則化のβをX·Xᵀの最大固有値から自動決定する機能を追加する
- **前提**: 現行は`beta=0.0`ハードコード（正則化なし）
- **方針**: cfgフラグ(`beta_auto`)で制御。`False`のとき現行動作を維持
- **beta_scale**: 長期的にグリッドサーチ対象とするため、他ハイパラ同様にリスト指定可能にする

## 計画

### Phase 1: optim.py 修正
- [x] `Tikhonov.__init__` のシグネチャに `auto=False, scale=1e-4` を追加
- [x] `get_Wout_opt` に分岐追加: `auto=True` のとき `beta = scale * max(eigvalsh(X_XT))`

### Phase 2: cfg.yaml 修正（train）
- [x] `beta_auto: false` フラグを追加
- [x] `beta_scale: [1.0e-4]` をリストで追加（グリッドサーチ対象）

### Phase 3: app_init.py 修正
- [x] `build_param_grid` の `param_names/param_values` に `beta_scale` を追加（`beta_auto=True` のときのみ展開）

### Phase 4: app.py 修正
- [x] `one_process` に `beta_auto=False` 引数を追加
- [x] `Tikhonov` 呼び出しを `Tikhonov(params["Nx"], Ny, auto=beta_auto, scale=params.get("beta_scale", 1e-4))` に変更
