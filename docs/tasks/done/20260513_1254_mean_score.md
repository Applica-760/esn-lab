# mean_score 判別戦略の実装

## 目的・前提・方針案

**目的**：`eval.judge` に `mean_score` 戦略を追加し、フレームスコア平均によるソフト集約を実験できるようにする

**前提**：
- `judgment.py` に `JUDGE_STRATEGIES` と `strategy` 引数接続は済み（20260511_1500_judge_strategy.md Phase1完了）
- `predictions` shape: `(n_frames, n_classes)`、`labels` shape: `(n_frames, n_classes)` one-hot
- `true_label` の決定は `majority_vote` と同じ（ラベルは確定値）

**方針**：
- `judgment.py` に `judge_sample_by_mean_score` を追加し `JUDGE_STRATEGIES` に登録
- `cfg.yaml` の `judge_strategy` を `mean_score` に切り替えて動作確認
- `app.py` / ダウンストリームは無変更

## 計画
