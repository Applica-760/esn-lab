## 目的・前提・方針案
- Conda `research` 環境から uv 環境へ移行し、ディストリビューション可能にする
- `projects/` は独立パッケージではないため toml 衝突なし
- ビルドバックエンド: setuptools（現状維持）
- 研究用依存: `[dependency-groups]` の `research` グループに追加（頒布物に含まれない）
- `yourpkg`（/home/takumi/share/research-prj）: 除外
- Python: `>=3.10`
