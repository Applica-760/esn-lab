# ID×条件の正誤・得票率ヒートマップ

保存済みの採食・反芻2クラスの予測結果を読み、同じIDの失敗がGroup・Fold間で繰り返されるかを比較します。学習・推論は行いません。

## 起動

```sh
cd /Users/murakamitakumi/Developer/projects/esn-lab
uv run -m projects.tasks.cli analysis.condition_heatmap
```

## 設定

同ディレクトリの`cfg.yaml`で指定します。

- `pred_result_dir`: `<Group>/<parameter>/<train|test>_results.npz`の参照先。JSONは対象外。
- `judgment_result_dir`: `<parameter>/judgment_results_<train|test>.csv`の参照先。
- `groups`・`parameters`・`fold_indices`・`modes`: 比較する条件。
- `output_dir`: 入力先と重ならない出力先。

初期設定は取得済み結果のGroup a〜j、Fold 0〜9、訓練・テスト、パラメータ1種類を使います。IDの真値・系列長が条件間で一致しない場合や、同じ条件にIDが重複する場合は停止します。

## 出力と読み方

`output_dir`に次を保存します。

- `config.lock.yaml`: 実行設定（通常CLI起動時）。
- `condition_cells.csv`: ID・条件・真値・再計算判定・両ラベルの票数と割合・保存判定との照合状態。
- `<parameter>/<train|test>_001.png`以降: 50 IDごとのヒートマップ。パラメータ別・訓練／テスト別に分け、全図でIDの行順を揃えます。
- `<parameter>/combined_001.png`以降: `modes`に訓練・テストの両方を指定した場合の混在図。テストのセルだけ白黒の二重枠で囲み、訓練は枠なし。同じID・条件に両方の結果がある場合は、上書きせずエラーで停止します。

縦はIDと真値、横はGroup/Foldです。色は**真値側への得票率**で、赤＝0%、黄＝50%、緑＝100%。全図で同じスケールを使います。

| 表示 | 意味 |
| --- | --- |
| 白・太字の`X` | 多数決の誤判定 |
| 灰色 | その条件にIDがない、または得票率を表示できない |
| `-` | 予測NPZファイルがない |
| `!` | 予測・保存判定の不正、または再計算と保存判定の不一致。色で得票率を示さず、詳細はCSVで確認 |
| `?` | 保存判定がなく照合できない。色は生出力から再計算した得票率 |

混在図でも得票率の色・X・行順は個別図と共通です。入力ファイルが不正な場合は、もう一方のモードの結果で隠さず`!`を表示します。両方にIDがないセルは灰色です。

各時刻の最大出力ノードに1票を与え、全保存時刻を集計します。warmup除去はせず、時刻内の同値・最終同票とも採食を選びます。50%の正誤は真値によって異なります。CSVの割合は0〜1、図は0〜100%です。欠落した割合はCSVでも空欄にし、0%と区別します。

同じIDの複数条件は独立したサンプルではありません。繰り返す失敗だけで入力品質や原因を断定せず、既存ビューアーで入力画像と生出力を確認してください。
